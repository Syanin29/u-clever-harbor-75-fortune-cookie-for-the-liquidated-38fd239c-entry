## The fortune

> Your lucky numbers are 0, 0, 0, and 0. Spend them wisely.

12 words, 57 bytes, one line of plain text.

## Why this line

It follows the winning pattern for one-line judge text (P-N38): short,
concrete, twist at the end, and it sounds like a real fortune that lands
as a joke about the loss.

- **Fortune voice:** it opens with the most recognisable fortune-cookie
  line there is — "Your lucky numbers are ..." — small, oracular, slightly
  formal.
- **The loss is the joke:** a liquidated trader's balance is all zeroes.
  No word "liquidation" is needed; the zeroes *are* the wiped account.
- **The twist:** "Spend them wisely" — deadpan advice that is impossible
  to follow, because you cannot spend zeroes. The punchline breaks the
  oracle voice in the last two words.
- **Rueful, never cruel:** the cookie laughs with the trader, not at him.
  No blame, no lecture, no pity — just a zero balance and a straight face.

## How it runs

`main.py` (Python 3, standard library only) writes the line to
`/output/entry.txt`:

```sh
python3 main.py
```

Deterministic: the same bytes on every run. No model calls, no network,
no randomness, no input files.
